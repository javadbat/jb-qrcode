<Title>Styling</Title>

`JBQRCode` has two styling layers. Use CSS variables and parts for the component shell, overlay, and download control. Use `dotsOptions`, `cornersSquareOptions`, and `backgroundOptions` for the generated QR SVG itself.

## Common Design Tokens

Use the core theme docs as the source of truth for shared design-system variables:

- [Theme Colors](../../jb-core/theme/stories/colors.mdx) explains the general color palette variables, default colors, customization approaches, and color generation helpers.
- [Theme Sizes](../../jb-core/theme/stories/sizes.mdx) explains shared size and radius variables.
- [Theme Custom Galleries](https://javadbat.github.io/design-system/?path=/docs/theme-custom-material--docs) gathers the shared custom style recipes across components.

QR code recipes should use those common tokens where possible, then map them into `--jb-qrcode-*` variables where the QR card needs a component-specific value.

## Styling Model

Use four layers when styling QR code examples:

- Common design tokens are documented in [Theme Colors](../../jb-core/theme/stories/colors.mdx) and [Theme Sizes](../../jb-core/theme/stories/sizes.mdx).
- Reusable example theme packs live in [`docs/styles`](https://github.com/javadbat/design-system/tree/main/docs/styles) and can be shared across components.
- Component recipe files live in [`modules/jb-qrcode/stories/styles`](https://github.com/javadbat/design-system/tree/main/modules/jb-qrcode/stories/styles).
- QR drawing options are JavaScript properties passed to `qr-code-styling`, so use them for dot shape, corner shape, gradients, logo, and QR background.

Each example uses one shared example theme pack from [`docs/styles`](https://github.com/javadbat/design-system/tree/main/docs/styles), one QR-specific recipe from [`modules/jb-qrcode/stories/styles`](https://github.com/javadbat/design-system/tree/main/modules/jb-qrcode/stories/styles), and a small set of `qr-code-styling` options in the story.

## Recommended Customization Path

1. Use `--jb-qrcode-*` variables first for the shell background, radius, padding, border, shadow, overlay, and download button.
2. Use `jb-qrcode::part(component)` for effects on the outer square surface.
3. Use `jb-qrcode::part(qrcode)` only for the generated SVG wrapper, such as centering or filters.
4. Use `jb-qrcode::part(overlay)`, `::part(download-button)`, and `::part(download-icon)` for hover-download affordances.
5. Use `dotsOptions`, `cornersSquareOptions`, and `backgroundOptions` when changing QR drawing shape or generated SVG colors.
6. Use common theme variables from [Theme Colors](../../jb-core/theme/stories/colors.mdx) and [Theme Sizes](../../jb-core/theme/stories/sizes.mdx) when the style should align with the design system.
7. Put reusable theme-pack values in [`docs/styles`](https://github.com/javadbat/design-system/tree/main/docs/styles) only when they should be shared by multiple component demos.

## Starter Recipe

Use this minimal recipe when a product only needs brand alignment for the QR card and overlay.

```css
jb-qrcode.brand-qrcode {
  --jb-qrcode-image-color: #1d4ed8;
  --jb-qrcode-bg-color: #ffffff;
  --jb-qrcode-border-radius: 0.75rem;
  --jb-qrcode-padding: 0.75rem;
  --jb-qrcode-border-width: 1px;
  --jb-qrcode-border-color: #dbe3ef;
  --jb-qrcode-box-shadow: 0 0.75rem 1.75rem rgb(15 23 42 / 0.14);
  --jb-qrcode-overlay-bg-color: rgb(29 78 216 / 0.64);
  --jb-qrcode-overlay-button-color: #ffffff;
  --jb-qrcode-overlay-button-bg-color-hover: #ffffff;
  --jb-qrcode-overlay-button-color-hover: #1d4ed8;
}

jb-qrcode.brand-qrcode::part(download-button) {
  border: 1px solid currentColor;
}
```

Use QR drawing options for generated SVG details:

```tsx
<JBQRCode
  className="brand-qrcode"
  value="https://javadbat.github.io/design-system/"
  dotsOptions={{ color: "var(--jb-qrcode-image-color)", type: "rounded" }}
  cornersSquareOptions={{ color: "var(--jb-qrcode-image-color)", type: "extra-rounded" }}
  backgroundOptions={{ color: "transparent" }}
/>
```

## Theme File Pattern

Use [Theme Colors](../../jb-core/theme/stories/colors.mdx) and [Theme Sizes](../../jb-core/theme/stories/sizes.mdx) as the common design-token guides. Theme-pack files should keep reusable demo variables in [`docs/styles`](https://github.com/javadbat/design-system/tree/main/docs/styles), then each component should keep its own style CSS in its story [`styles`](https://github.com/javadbat/design-system/tree/main/modules/jb-qrcode/stories/styles) folder.

```css
/* https://github.com/javadbat/design-system/blob/main/docs/styles/carbon.css */
.theme-name-style {
  /* shared design-system variables */
}

/* https://github.com/javadbat/design-system/blob/main/modules/jb-qrcode/stories/styles/style-carbon.css */
jb-qrcode.theme-name-qrcode {
  /* QRCode host variables */
}

jb-qrcode.theme-name-qrcode::part(download-button) {
  /* official download surface */
}
```

This keeps common theme tokens reusable while making the official `JBQRCode` styling API visible in one page.
